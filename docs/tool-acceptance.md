# 15 个工具的验收矩阵

这些检查是夹具、本地示例和浏览器界面，不是在线模型的教学正确性证明。通过只说明结构、数字和权限没有明显坏掉。真正按年级和学科看生成质量，要等以后用配置好的模型再跑。

本地示例不调用模型。页面上若写着「当前为本地示例」，结果来自 `src/lib/ai/mock.ts`。

## 部署边界

账号、点数和生成记录写在本机 `data/store.json`。密码用 scrypt，登录 cookie 是 httpOnly。生成、导出和识别都先看当前登录用户，不能凭别人的编号读取。识别图片不进这份 JSON，也不进浏览器草稿。

内部测试使用本机 PostgreSQL。点数预留、幂等和备份说明在 [operations.md](operations.md)。主机上要另装 Tesseract。这还不是对外服务。

## 矩阵

| 工具 | 夹具要卡住的情况 | 本地示例里已看到的行为 | 还不能当成教学结论 |
| --- | --- | --- | --- |
| AI出课 | 各段分钟合计必须等于所选课时；要有检查题。合计行和其他表不算。 | 小学口述和检查题用短句。20/40/45 分钟都能加总。 | 不证明这节课好讲。 |
| AI备课 | 节奏表合计必须是 40 分钟。 | 示例表是 40 分钟。 | 不证明符合某套教材。 |
| AI讲义 | 练习节在参考答案节前面。 | 示例把答案放在最后。小学数学示例用加法，不用一次函数。 | 不证明例题适合该年级。 |
| AI教辅制作器 | 分页行数等于所选页数；只要 1 页时不能再编练习页。 | 示例按所选页数切片。 | 不证明能装进一页纸。 |
| AI预习 | 正文要出现所选分钟数。 | 小学说明由家长读，并写上分钟数。 | 不证明孩子真能在时限内做完。 |
| AIPPT | 幻灯片张数必须等于所选页数。下载 PPTX 不扣点，且只读自己的记录。 | 可下载 PPTX，也能打印 HTML。公式是文字。 | 不证明讲稿适合该听众。 |
| AI可视化 | 能确定的一次函数按 k、b 作图；字母式、二次式和多个式子不画假直线。 | 小学到高中同一套图规则。 | 不证明图像讲解完整。 |
| AI讲题 | 结果要对照原题里的片段。 | 能识别的一次函数会算出截距；识别不了就不编得数。 | 不证明步骤满分。 |
| AI组卷 | 题量一致，每题正分，合计接近 100，并写上建议分钟数。 | 本地示例合计 100 分。小学数学用 20 以内加减，不用一次函数；小学语文、英语用短句。 | 不证明难度符合课标。 |
| AI作业批改 | 分数是 0 到 100 的整数，并引用学生文字。图片要先识别并确认才写入。失败不扣点。 | 印刷体识别依赖本机 Tesseract。手写未测，不能当手写可用。 | 不证明评分公正。 |
| AI试卷变式 | 变式数量必须等于所选数量，每题有题干和答案。 | 示例按所选杠杆改一处。 | 不证明和原题同方法。 |
| AIWORD | 至少两段，并保留用户正文；两位数及以上的数字不能改。DOCX 不扣点。 | 可下载 DOCX，也能打印 HTML。公式是文字。 | 不证明版式适合印刷厂。 |
| AI举一反三 | 正好 3 道题，且能看到用户写的错法片段。 | 示例按错因递进。 | 不证明三道题由易到难。 |
| AI试卷分析 | 错题表只留一张；得分高于满分时必须写明异常。 | 示例会提示得分高于满分。 | 不证明归因正确。 |
| AI提分评测 | 周数必须一致，并写上最近分和目标分。每周平均超过 8 分时要建议把目标改近。 | 示例按周数排表。 | 不证明目标一定能达到。 |

四个字的片段重叠只用来避免结果完全跑题，不能当成质量通过。空结果、错数量、改数字、别人的记录和失败请求都应被拒绝，且不扣点。分钟和页数的下拉框收起后显示「20 分钟」「1 页」，不只显示数字。
